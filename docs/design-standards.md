# Mao.MEOW 设计规范

---

## 核心设计语言

### 一句话概括
**硬核科技词 × 猫咪慵懒行为** — 表面一本正经搞科技，背后全是猫的逻辑。

### 视觉公式
**线条发光 > 实心填充** — 所有 Logo、图标、装饰元素用霓虹轮廓线，而非色块。

---

## 组件设计规范

### 1. 品牌 Logo
- 猫爪轮廓（1 主肉垫 + 3 趾垫）+ 两侧各 3 条胡须
- 线条风格，像电路板走线
- 霓虹发光渲染（非实心填充）
- 有完整版（带 Mao.MEOW 文字）和缩小版（仅图形，Header 用）

### 2. 导航 Header
- 固定顶部，`height: 64px`
- 背景：`rgba(5, 5, 16, 0.85)` + `backdrop-filter: blur(8px)`
- 导航项：白色文字，hover 变喵青 + 底部下划线动画

### 3. 卡片（品牌宣言 / 产品 / 团队工牌）
- 背景：`rgba(10, 10, 30, 0.7)`
- 边框：`1px solid rgba(0, 240, 255, 0.15)`
- hover：边框变喵青 + 多层霓虹 box-shadow
- 圆角：12px
- 内边距：30px

### 4. 按钮
- 主按钮：霓虹边框 + 透明背景，hover 填充喵青半透明
- 文字：等宽字体，字母间距 2px
- 圆角：4px
- 示例：`[ 探索产品 ]` `[ 入侵公司网络 ]`

### 5. 产品卡片（横向滚动）
- 最小宽度：500px（桌面）
- 布局：左侧产品图 + 右侧文字信息
- scroll-snap 吸附
- 状态标签：「量产中」终端绿 / 「实验室阶段」紫色

### 6. 团队工牌卡片
- 图片：线条剪影/证件照 + 霓虹发光轮廓
- KO 卡片居中且略高于其他（`transform: translateY(-20px)`）
- 技能条：星标 Unicode ★☆☆☆☆，喵青色

### 7. 时间线
- 左侧竖线：1px 霓虹青色
- 每条日志：左侧终端绿时间戳 + 右侧白色标题
- hover 标题变喵青

### 8. 联系表单
- 输入框：暗底 + 霓虹边框，focus 时发光
- 下拉选择：统一样式
- 提交按钮：霓虹风格，文字「发送至猫砂盆」
- Toast：居中弹出，3 秒消失

### 9. Section 隔断
- 4px 高扫描线纹理
- CSS repeating-linear-gradient 实现
- 颜色：`rgba(0, 240, 255, 0.06)`

## 动效规范

### 进入动画（竖瞳扫描仪）
| 阶段 | 时长 | 描述 | 缓动 |
|------|------|------|------|
| 1. 扫描 | ~1.5s | 扫描线降下 | ease-out |
| 2. 竖瞳 | ~2.0s | 瞳孔睁开 + 字符流 | ease-in-out |
| 3. 绘制 | ~2.5s | Logo 绘制 + 打字 | ease-out |
| 4. 过渡 | ~1.0s | 淡入主页 | ease |

**总计约 7 秒。** 首次访问播放，再次访问跳过（localStorage 标记）。

### 滚动入场
- 触发点：元素进入视口 15% 时
- 动画类：
  - `.reveal-fade-up`：从下方 40px 上滑 + 淡入
  - `.reveal-fade-in`：纯淡入
  - `.reveal-blur-in`：模糊 → 清晰 + 淡入
- 时长：0.8s，ease-out

### 持续动画
- Hero 图腾呼吸：6s 周期，sin 曲线调制 opacity 和 scale
- 浮动粒子：4-12s 随机，从底部向上飘，linear
- 弹幕：8-15s 随机，从右到左，linear 无限循环
- 向下箭头：1.5s 上下弹跳，ease-in-out 无限

### Hover 交互
- 导航链接：0.2s 颜色过渡
- 卡片：0.4s 边框 + 阴影过渡
- 按钮：0.3s 背景色过渡
- 产品图：0.3s drop-shadow 增强

## 文案语调规范

### 核心反差
用严肃的科技公司口吻描述猫咪的慵懒日常。关键词混搭：
- 硬件词：传感器、协议、信号、编译、频率、带宽
- 猫词：呼噜、肉垫、罐头、踩奶、纸箱

### 示例
- ✅ "全球领先的呼噜声波导流技术"
- ✅ "本产品经过严格的防咬合测试"
- ✅ "您的简历已进入猫砂盆，请耐心等待"
- ❌ 避免过于卖萌或低幼化的表达

### 角色语调
| 角色 | 风格 | 标志语 |
|------|------|--------|
| KO (CTO) | 冷峻寡言 | "这个方案，不够香。" |
| 花花 (CMO) | 热情社交 | "合作吗？先让我蹭蹭你。" |
| D (COO) | 自嘲务实 | "赚钱给猫花。" |

## 角色设定（用于生成内容）

### KO — CTO 首席技术官
- 基因：美短银虎斑（公）
- 形象：左眼带精密扫描仪，厌世神情，脖子上挂工牌
- 人设：负责核心技术，冷峻寡言，决策时只说"喵"
- 赛博人格：终端命令行人格，看世界是代码流

### 花花 — CMO 首席市场官
- 基因：长毛金点（公）
- 形象：全息投影毛发蓬松，开心自拍大头照，轻微运动模糊
- 人设：负责连接人类世界，能说会道
- 赛博人格：霓虹广告牌人格，永远在眨眼

### D — COO 首席运营打杂官
- 基因：人类（女）
- 形象：Q版半身像，银框眼镜，棕色长发，歪头歪嘴笑，比赞手势
- 人设：伺候二位老板、测试充电线、暖腿服务
- KPI/OKR 全系猫咪心情制定，年终奖按踩奶次数计算
